# Aurevon — Luxury Brand Landing (Navbar + Hero)

React 18 + TypeScript + Vite + Tailwind CSS 3 single-page landing: fixed navbar
with full-screen overlay menu, and a full-viewport video hero.

## วิธีรัน

```bash
npm install
npm run dev
```

เปิด `http://localhost:5173`

## Build

```bash
npm run build
npm run preview
```

## โครงสร้างไฟล์

```
src/
  components/
    Navbar.tsx   — navbar fixed, overlay menu, hamburger morph
    Hero.tsx     — full-viewport video hero
  App.tsx
  main.tsx
  index.css
```
